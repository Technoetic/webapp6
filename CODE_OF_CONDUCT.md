# Code of Conduct

## Our Pledge

We pledge to make participation in `webapp6` a respectful, constructive, and harassment-free
experience for everyone, regardless of background or experience level.

## Expected Behavior

- Use welcoming, clear, and evidence-based technical language.
- Focus feedback on code, rules, packaging, and documentation rather than individuals.
- Respect project boundaries, security policies, and maintainers' time.

## Unacceptable Behavior

- Harassment, personal attacks, trolling, or discriminatory comments.
- Publishing others' private information or submitting malicious payloads.

## Reporting

Report conduct concerns privately via GitHub security/maintainer channels or open a respectful
issue when appropriate. Maintainers may remove content or restrict access for violations.
